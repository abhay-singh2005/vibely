# Vibely

**Share your vibe.** A polished React frontend for a modern social experience.

## Features

Responsive feed, stories, explore grid, post interactions, profile, notifications, messaging UI, saved states, settings, dark mode, and authentication-ready routing with realistic mock data.

## Tech Stack

React, Vite, Tailwind CSS, React Router DOM, Lucide React, and Axios.

## Installation

```bash
npm install
npm run dev
```

Build for production with `npm run build`.

## Environment Variables

Copy `.env.example` to `.env` and set `VITE_API_URL` when a backend is available.

## Future Backend Integration

The UI is deliberately data-driven. Replace mock data calls with Axios services for auth, users, posts, comments, stories, notifications, and messages while retaining the existing component contracts.

## Future Features

Real authentication, media uploads, realtime messaging, moderation, and personalized recommendations.
